## The frozen design plan (verbatim from `docs/spec/spec-v1.8.0-delta-1.md`)

Normative and frozen: implement it, do not redesign any part of it.

**Direction.** An operator's instrument panel, not a SaaS analytics
product: hairline rules, not floating cards; one accent reserved for
measured signal; numbers in columns you read down.

**Palette — exactly six named values**, custom properties on `:root`
inside the one `STYLE` block:

| token | hex | role |
|---|---|---|
| `--ink` | `#16181c` | body text, headings, the one heavy rule under `h1` |
| `--ground` | `#eef0f2` | the page background: cool paper, never warm cream |
| `--plate` | `#ffffff` | the surface of a panel/section, flat |
| `--rule` | `#ccd2d8` | every hairline: panel edges, row rules, chart baselines, the `h2` scale line |
| `--dim` | `#5f6873` | secondary text: column headers, units, timestamps, footer |
| `--signal` | `#1f5fb0` | the single accent: bar fill, link, active nav item, focus ring — signal only |

Two status colours carry over unchanged and are the only other saturated
values: ok `#1c7a4a`, fault `#b23636`, on status text and an error-outlined
gantt bar, nowhere else. A ninth colour is a defect.

**`PALETTE` remap — same 5 keys, new literals only:**

| key | new literal | role |
|---|---|---|
| `bar` | `#1f5fb0` (`--signal`) | bar fill |
| `bar_track` | `#eef0f2` (`--ground`) | bar track |
| `kind_client` | `#1f5fb0` (`--signal`) | a `CLIENT` span |
| `kind_internal` | `#5f6873` (`--dim`) | an `INTERNAL` span |
| `error_outline` | `#b23636` (fault) | unchanged |

**Type scale — four sizes, two weights, one face** (the existing system
stack, for everything including numbers):

| element | size / line-height | weight | notes |
|---|---|---|---|
| `h1` | 22px / 1.25 | 600 | `letter-spacing: -0.01em`; one 2px `--ink` rule beneath, full content width |
| `h2` | 16px / 1.3 | 600 | sentence case; a 1px `--rule` line from the text's right edge to the content's right edge — a scale line, not decoration |
| `h3` | 13px / 1.35 | 600 | sentence case |
| body, `td` | 13px / 1.5 | 400 | |
| `th`, `.meta`, `footer`, units | 12px / 1.4 | 600 (`th`) / 400 (rest) | `--dim`; sentence case, `text-transform: none`, `letter-spacing: 0` |

Four sizes and no fifth: 22 → 16 → 13 → 12. `h3` is deliberately body size
at the heavier weight — weight is the distinction, not a fifth size. No
300 or 700 weight, no italic.

**Alignment.** One column, `max-width: 68rem`, centred, and every element
— `h1`'s rule, each `h2`'s scale line, every plate/table/`<svg>` — shares
its left and right edges. Text left-aligned, nothing centred but a single
empty-state line; every `class="num"` cell is right-aligned with
`font-variant-numeric: tabular-nums` in the body face (this is what makes
DSH-03's coverage rule checkable); units go in the column header, never
per cell; charts drawn to the table's content width so bar baselines line
up with table rules.

**Surfaces.** A `section` is a plate: `background: var(--plate)`, `border:
1px solid var(--rule)`, `border-radius: 2px`, **no `box-shadow` anywhere**,
padding `0 1rem 1rem`. Table rows separated by 1px `--rule`, last row
none. A bar is a 0.6rem `--ground` track with a `--signal` fill, square
ends.

**Layout, per page (for reference — you only build the section builders
and the reading-strip builder; wiring into routes is T6's)**:

| page | concept |
|---|---|
| `/` (usage) | a reading strip across the top of the first plate: four measured values — calls, total tokens, cost, error rate — as label-above-number pairs on one baseline, split by 1px `--rule` verticals, numbers at 22px/600 tabular; then the totals table, then the by-group table |
| `/traces` | one full-width table, newest first; duration column carries an inline `--signal` bar sized against the page's widest duration, drawn inside the number's own cell |
| `/traces/<id>` | the gantt on its own plate first, span table beneath, both at content width |
| `/tools` | the tool-health table on one plate, the limit-hits bar chart on the next, drawn to the same width |
| `/conversations` (T5's, not yours) | — |
| `/conversations/<id>` (T5's, not yours) | — |

**What this deliberately is not.** Warm cream, a serif display face, card
shadows, ALL-CAPS eyebrows, middle-dot meta strings, monospace data, an
arrow after link text — all rejected; this is the closed list DSH-04's
scanner checks for.

## What to write (test-first)

1. **`STYLE` rewritten wholesale** to the plan above: the six palette
   custom properties on `:root`, the two status colours, the type scale,
   the plate/section rules, no shadow, `td.num, th.num` keeps
   `font-variant-numeric: tabular-nums` and **drops** the monospace
   `font-family`. `page()`'s signature and shape (one `<style>` block, no
   `<script>`, no external URL) stay exactly as they are.

2. **`class="num"` coverage, by declared column spec** (REQ-V180-DSH-03):
   each table-emitting builder (`usage_section`, `tool_health_section`,
   `trace_list_section`, and `trace_tree_section` if it renders a table)
   gets an explicit, ordered `(heading, kind)` column spec —
   `kind ∈ {"num", "text"}` — and emits `class="num"` on the `<th>` and on
   **every** `<td>` of a `"num"` column (placeholder cells included, e.g. a
   `—` in a numeric column keeps the class), on neither for `"text"`. The
   heading's own wording is irrelevant to its kind; kind is declared, never
   inferred from cell content.

3. **The rejected-defaults scan** (REQ-V180-DSH-04): fix `tool_health_section`'s
   middle-dot summary join (`:425-433`) to not use `·`, and drop the `th`
   uppercase rule (`text-transform: uppercase`, `STYLE:113-114`) — both
   already flagged live in the current tree, so your own new test
   (`T-V180-DSH-02`) must be red against the unmodified tree first, to
   prove it's a real gate.

4. **The reading-strip builder** — a new pure function in
   `dashboard_render.py` (name your own, following this module's existing

   totals (calls, total tokens, cost, error rate) and rendering the
   label-above-number strip per the layout table above. It is **not**

5. **SVG palette remap** (REQ-V180-DSH-06): only the five `PALETTE` string
   literals change, per the table above. `_bar_chart_svg`, `histogram_svg`,

6. **Tests** in `tests/test_v180_dashboard.py` (create it): `T-V180-DSH-01`
