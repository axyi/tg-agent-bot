## The decided DDL (REQ-V190-STO-02), verbatim

```sql
CREATE TABLE IF NOT EXISTS documents (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id     INTEGER NOT NULL,
    filename    TEXT    NOT NULL,
    file_type   TEXT    NOT NULL CHECK (file_type IN ('txt', 'md', 'docx', 'pdf')),
    created_at  TEXT    NOT NULL,
    size_bytes  INTEGER NOT NULL,
    text_chars  INTEGER NOT NULL,
    page_count  INTEGER,
    chunk_count INTEGER NOT NULL,
    sha256      TEXT    NOT NULL,
    UNIQUE (user_id, filename)
);

CREATE TABLE IF NOT EXISTS chunks (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    document_id INTEGER NOT NULL REFERENCES documents(id) ON DELETE CASCADE,
    chunk_index INTEGER NOT NULL,
    text        TEXT    NOT NULL,
    page        INTEGER,
    char_start  INTEGER NOT NULL,
    char_end    INTEGER NOT NULL,
    UNIQUE (document_id, chunk_index)
);
CREATE INDEX IF NOT EXISTS idx_chunks_document ON chunks (document_id, chunk_index);
```

## The 5→6 migration (REQ-V190-STO-03), exact control flow

Not `executescript`. `storage._migrate_5_to_6(conn)`:

```python
def _migrate_5_to_6(conn: sqlite3.Connection) -> None:
    conn.execute("PRAGMA foreign_keys=OFF")   # no transaction is active here
    try:
        conn.execute("BEGIN IMMEDIATE")
        for statement in _MIGRATION_5_TO_6:   # the steps (1)-(3) below
            conn.execute(statement)
        conn.execute("COMMIT")
    except BaseException:
        conn.execute("ROLLBACK")
        raise
    finally:
        conn.execute("PRAGMA foreign_keys=ON")
    assert conn.execute("PRAGMA foreign_keys").fetchone()[0] == 1
    assert conn.execute("PRAGMA foreign_key_check").fetchall() == []
```

`_MIGRATION_5_TO_6` statement list: (1) `_DOCUMENTS_DDL` (the `documents`
and `chunks` DDL above, same object `_DOCUMENTS_DDL` reused by fresh-schema
creation); (2) rebuild `llm_calls` by rename-copy — `CREATE TABLE
llm_calls_v6 (…)` with the **same columns in the same order** as the live
table (`storage.py:66-95`'s v4 DDL plus the two v5 columns
`reasoning_requested TEXT`, `reasoning_honored INTEGER` at `:246-250`) and
`CHECK (purpose IN ('agent', 'summary', 'rerank'))`, `INSERT INTO
llm_calls_v6 (<explicit column list>) SELECT <same list> FROM llm_calls`,
`DROP TABLE llm_calls`, `ALTER TABLE llm_calls_v6 RENAME TO llm_calls`,
`CREATE INDEX IF NOT EXISTS idx_llm_calls_conv ON llm_calls (conv_id, id)`;
(3) `UPDATE schema_version SET version = 6 WHERE id = 1`.

`init_schema` applies it right after the 4→5 step
(`storage.py:329-330`): `if schema_version(conn) == 5:
_migrate_5_to_6(conn)`. Accepted-version set at `:315` becomes `(1, 2, 3,

## STO-04 — the `rag.embedding` pair, exact rebind rule

`init_schema(conn, *, embedding_dim: int | None = None, embedding_model:
str = "")`. `vec_chunks`'s dimension is fixed at creation, so:

- **First creation** (no `rag.embedding` key in `bot_state` yet): in one
  `BEGIN IMMEDIATE … COMMIT` — if `vec_chunks` already exists in
  `sqlite_master` and `document_count_all(conn) == 0`, `DROP TABLE
  vec_chunks` first (orphan recovery); if it exists and a document exists,
  raise `ConfigError("vec_chunks exists without a rag.embedding pair while
  documents exist; delete the documents (see README Limitations) before
  configuring EMBEDDING_MODEL/EMBEDDING_DIM")` **without altering
  anything**; otherwise `CREATE VIRTUAL TABLE vec_chunks` at the configured
  dimension and `set_state('rag.embedding', f"{model}:{dim}")` — table and
  state write commit **together**, never separately.
- **Later starts**, pair present and differs from the stored one — decided
  by `document_count_all(conn)` read **before any DDL**: a document exists
  → `ConfigError("EMBEDDING_MODEL/EMBEDDING_DIM differ from the indexed
  pair <stored>; delete the documents (see README Limitations) before
  changing them")` before any DDL, no state altered; `document_count_all ==
  0` → one transaction does `DROP TABLE IF EXISTS vec_chunks`, delete the
  `rag.embedding` key, `CREATE VIRTUAL TABLE vec_chunks` at the configured
  dimension, write the new pair (covers both a model-only and a
  dimension change).
- A **matching** pair is idempotent — no drop, no rewrite.
- A start with no embedding config and a stored pair is allowed (documents
  simply unreachable, CMD-01's job, not T1's).

Three `bot.py` callers (`:1272`, `:1395`, `:1541`) will eventually pass
`embedding_dim=cfg.embedding_dim, embedding_model=cfg.embedding_model` —
that plumbing is **T6/T7's job, not T1's**; T1 only needs `init_schema`'s
signature and behaviour to be correct and byte-compatible with every
existing call site (`embedding_dim=None` default ⇒ no `vec_chunks` DDL,
current behaviour, REQ-V190-EC-05). `devtools/bench.py:927`'s call stays
untouched (`None`).
