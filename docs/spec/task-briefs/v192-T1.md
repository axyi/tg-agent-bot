Decision procedure per finding, in this order; the first that applies wins,
and the report records which one:

1. **Interface-mandated** (signal handler `signum, frame`; `http.server`
   `log_message(self, format, *args)`; a protocol/ABC method; a callback
   whose caller passes the argument): keep the signature, suppress inline
   with a comment naming the interface. skylos honours `# skylos: ignore`
   on the line — verify the exact pragma against `skylos --help` / its
   docs at 4.35.0 before relying on it; if 4.35.0 has no inline pragma,
   rename the parameter with a leading underscore only when the caller
   passes it positionally, otherwise leave it and count it as
   "unresolvable at this pin".
2. **Referenced by a `find` string** in `devtools/mutation_check.py`, by a
   test, by `checks.py`, or via reflection/`getattr`/string lookup: keep,
   suppress inline with the reference named. Check `_MIGRATION_2_TO_3`
   first — a migration table flagged unused is the highest-consequence
   false positive in the list (`grep -rn _MIGRATION_2_TO_3 --include=*.py`
   and `git log -S_MIGRATION_2_TO_3 --oneline`).
3. **Genuinely dead and the author's own orphan is not the question here —
   this is pre-existing code**: the lab rule says surface, don't delete,
   *unless* the operator has asked for the cleanup — and for this task the
   operator has (handoff: "исправление всех проблем"). So: delete when
   (a) no reference exists anywhere in the tree (`grep -rn`, including
   `docs/` and `evals/`), (b) `git log -S<name>` shows why it was added
   and that reason is gone, and (c) the deletion leaves gate 6 at
   `0 drifted`. Record `(a)(b)(c)` evidence per deletion in the report.
4. **Uncertain**: leave it, list it as such with the reason.
