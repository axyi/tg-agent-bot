## What to add, verbatim

Add next to `split_message` in `bot.py`:

```python
def utf16_length(text: str) -> int:
    """Telegram counts UTF-16 code units, exactly as `split_message` does."""
    return sum(2 if ord(char) > 0xFFFF else 1 for char in text)


def reply_parts(text: str) -> list[str]:
    """Redact first, then split: a secret can never straddle a part boundary."""
    return split_message(redact(text))
```

(`redact` is `config.redact`, already imported or importable in `bot.py` —
check the existing import; `_send` already calls it per-part.)

   `not text.strip()` to `NON_TEXT_REPLY` before any LLM call and before
   `storage.add_user_message`. Write a test proving it for a whitespace-only
   message (`"   \n\t "`): exactly one `NON_TEXT_REPLY` reply, `llm.calls == []`,
   zero `messages` rows, conversation count unchanged.

2. **SAN-02**: `bot.py:877` currently reads `if len(text) > MAX_MESSAGE_CHARS:`
   (code points). Change it to `if utf16_length(text) > MAX_MESSAGE_CHARS:`.
   `MAX_MESSAGE_CHARS = 4000` (`bot.py:53`) and `TOO_LONG_REPLY` (`bot.py:68`)
   are unchanged; the check keeps its position before the rate limiter
   (`bot.py:881-884`). Pin the boundaries: 2,001 × `U+1F600` (4,002 UTF-16
   units) is rejected with `TOO_LONG_REPLY`, no LLM call, no row; 2,000 ×
   `U+1F600` (4,000 units) passes to the LLM; 4,000 BMP characters pass;
   4,001 BMP characters are rejected; the over-length message must not
   consume a rate-limit token (verify `tests/test_v1_guardrails.py:556`,
   `:571` stay green unamended).

3. **OUT-01**: replace **every** `split_message(` call site in `bot.py` with
   `reply_parts(`  — the agent reply (`:993`), `/status` (`:901`), `/stats`
   (`:917`), `/summary` (`:1072`), `/documents` (`:1474`). After the edit,
   `split_message(` must occur in `bot.py`'s source exactly twice: its own
   `def` line and inside `reply_parts`'s body. `_send` (`bot.py:1490-1500`)
   keeps its own per-part `redact` call unchanged (defence in depth,
   idempotent). `split_message` itself must not change
