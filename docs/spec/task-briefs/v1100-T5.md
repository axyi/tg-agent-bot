## LAT-02/LAT-03 — the recorder and the TTFT probe (read §9 in full, both REQs)

`RequestRecorder`: an object with a `.hook(request)` method suitable for
`httpx.Client(event_hooks={"request": [recorder.hook]})`. It records the
**most recent** request whose `request.url.path` ends in
`/chat/completions`: store `url` (`str(request.url)`), `headers` (a dict —
`dict(request.headers)`, or however `httpx.Headers` iterates cleanly),
`content` (the raw body bytes, `request.content` — read it without
consuming the stream if `httpx` requires special handling; a plain
`httpx.Client` request with a JSON body has `.content` available
synchronously via the event hook). Expose it as `.current` or similar,
readable by `RecordingLLM`.

`probe_headers(headers: dict) -> dict`: a copy of `headers` with these five
names removed, **case-insensitively**: `Content-Length`,
`Transfer-Encoding`, `Connection`, `Host`, `Accept-Encoding`. Everything
else (notably `Authorization`, `Content-Type`, `Accept`) stays byte-equal.

`ttft_probe(client, cfg, recorded, *, clock) -> float | None`: only called
by `run()` when `recorded.url` is under `cfg.lmstudio_base_url` (string
prefix check) — the caller decides this, or the probe itself checks it and
returns `None`/is skipped, your call, but the table-printing logic must
show `ttft: n/a (<provider>)` when not called, per LAT-01. When called: `body
= json.loads(recorded.content); body["stream"] = True`; re-post with
`client.stream("POST", recorded.url, headers=probe_headers(recorded.headers),
content=json.dumps(body).encode(), timeout=cfg.llm_timeout_s)`; time from
before the request to the first SSE line starting with `data: ` whose
parsed JSON `choices[0].delta` has a non-empty `content` **or**
`reasoning_content`/`reasoning`; close the stream right after. `[DONE]`
with no such event → `None`. Any `httpx` error / non-200 status / other
exception → let it propagate to the **caller** in `run()`, which catches it
and prints `ttft: error (<class name>)` — the probe function itself can
either catch-and-return-a-sentinel or raise; whichever is cleaner, just
make sure `run()`'s printed table matches ERR-01 row 13 exactly. Never
changes the exit code.
