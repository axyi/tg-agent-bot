# Telegram-пост — прогон spec-v1

Готов к копированию (всё ниже разделителя).

---

**Замечания с разбора ДЗ-3 закрыл спецификацией, а не патчами**

Условия: не переписывать v0, а написать **дельта-спеку** поверх неё — таблица
поправок вместо форка. Изоляция `exec`, context repair сломанного JSON, таймаут
обязан убивать процесс, явные лимиты входа/выхода, поведение при ошибках и
security — в спеке, критерии приёмки (Gherkin) — до кода.

90 требований REQ-V1, и claude-opus-5 (Claude Code) по одному промпту
`go docs/spec/spec-v1.md` собрал: `exec` в одноразовом контейнере (без сети,
non-root, read-only rootfs, 512 МБ / 1 CPU / 128 pids, все capabilities
сброшены) — без фолбэка на хост; redaction секретов на всех путях наружу;
аудит-лог; allowlist-fetch; повтор при malformed-ответе; нотис при обрезке по
`max_tokens`; бюджет контекста; failover LM Studio → OpenRouter; структурные
саммари диалога; команды и rate limit; пятый гейт `--selftest-live`,
проверяющий живое окружение за 0 токенов.

Метрики:
• спека — ≈20k токенов (1474 строки, 77 КБ)
• промптов к модели — 2 (реализация + ревью в чистом контексте)
• с первого прогона — да: все 5 гейтов зелёные, 197 тестов
• тестов стало 203 (было 113); 9 Gherkin-сценариев прогнаны против живого
  Docker / LM Studio / OpenRouter, 5 ждут реального tg-id оператора
• 1 цикл починки: ревью нашло, что **две ключевые security-развязки переживали
  мутацию с 197 зелёными тестами**
• claude-opus-5: 35,5M in (34,8M — кэш) / 243k out; ≈ $27,8 по открытым
  API-ценам (реально — flat-rate)

Вывод злее прошлого: зелёные тесты не доказывают, что код делает то, что обещает
README. Доказывает мутация.
