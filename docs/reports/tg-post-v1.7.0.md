tg-agent-bot v1.7.0 — reasoning-политика по цели вызова, без тега

Условия: `LLM_REASONING_POLICY` (model-default/off/by-purpose) +
`LLM_REASONING_ON_PURPOSES` — точечное выключение рассуждений по цели
вызова; wall-clock бюджет на саммари (пол 30s); `bench.py` расширен
(сопоставимость раннов, `meta.reasoning`, гейт 3/3, `--tag`). Живой
многочасовой бенчмарк трёх кандидатов, гейт по стоимости ≤0.70×
baseline.

Результат: качество прошло (C1: 54/54, S13–S18 все 3/3), стоимость —
нет: 0.908× вместо ≤0.70×. Эффект настоящий (латентность саммари
53629→12720 мс, −76%), но реасонинг реально выключается только на
summary-вызовах (6 из 150+) — мало для агрегированного порога. Код
смержен (C1 — новый дефолт), тег `v1.7.0` не создан — так предписывает
спека при FAIL по cost-гейту. Раскрыто по пути, не спрятано: баг в
доках (семантика `LLM_REASONING_ON_PURPOSES` описана наоборот),
пропущенные CLI-флаги метаданных у кандидатов (исправлено до коммита),
устаревшая цифра skylos в самой спеке (19 против измеренных 8/13).

Метрики: исполнитель — claude-sonnet-5 (Claude Code). Спецификация
≈222 КБ, 23 коммита, промпты 103–123. Repair-бюджет: 0 из 5 — находки
пойманы до покраснения гейтов либо это ревью-фиксы; внешние отказы
гейтов — подпись коммитов (1Password) и адрес LM Studio, не код.
Токены исполнителя харнесс не показывает (`docs/llm-usage.md`, строки
58–61); LM Studio-инференс: $0.172 + $0.146 = $0.318, локально, $0
маржинальных.
