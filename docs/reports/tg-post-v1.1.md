# Telegram-пост v1.1

---

**Патч закрыл то, что нашёл аудит v1 — по спеке, а не по фидбеку**

Условия: только названное аудитом, без рефакторинга v1. Security-проба
нашла 8 находок (секрет мимо редактора при цитировании моделью, обрезка
режет секрет пополам, контейнер переживает смерть бота, sandbox без квоты
диска, SSRF через allowlist, `EXEC_WORKDIR=/etc` проходил, хостовый DNS
утекал в контейнер); compliance-ревью намутировало тесты 37 раз — 4 мутации
выжили.

claude-sonnet-5 (Claude Code), один промпт `go docs/spec/spec-v1.1.md`,
закрыл всё: redaction на ответе модели и tool-call аргументах + last-line
guard в `storage.py`; truncation с запасом на длину секрета перед обрезкой;
label + reap осиротевших контейнеров + `timeout(1)` в контейнере; квота
диска sandbox с отказом до старта контейнера; валидация SSRF-allowlist и
`EXEC_WORKDIR` строго внутри проекта; пустой `/etc/resolv.conf` вместо
хостового.

Метрики:
• тестов 251 (было 203); все 4 мутации доказаны вручную: строка → красный →
  возврат → зелёный
• Appendix B — 11 живых сценариев на реальном Docker, все PASS, без единого
  сообщения в Telegram
• claude-sonnet-5: 82,0M in (81,4M кэш) / 229,8k out + ревью-агент 158,9k;
  ≈$19,9 по открытым ценам (flat-rate по факту)
• 1 цикл починки: отчёт сослался на файл, писавшийся параллельно с ревью, +
  пропуск ре-проверки квоты sandbox
