tg-agent-bot v1.8.0 — контекстная дисциплина, чат-UX, дашборд, беседы

Условия: AGENTS.md без Context discipline (v1.7.0 делегировал 1 задачу
из 13); статус-сообщение засоряло чат; дашборд «непонятная штука,
цифры плывут»; ни списка бесед, ни транскриптов.

Результат: все 4 темы реализованы. AGENTS.md — Context discipline +
ownership-zone; статус удаляется при успехе, typing-индикатор во время
обработки, провал — структурный AgentOutcome, не text-matching;
дашборд переработан под frozen design plan (6-цветная палитра,
class="num" по декларации колонки); /conversations +
/conversations/<id> с редакцией на обоих sink'ах и байт-бюджетной
пагинацией по ходам. 98/98 мутаций убиты, full-профиль зелёный.

Раскрыто, не спрятано: 2 operator-authorized эрраты (EC-03 не учёл 2
теста, сломанных явными MUST; старый тест сломан repoint'ом RPT-01);
1 процессное отклонение (субагент подмешал тест-фикс в свой коммит
вместо эскалации); свой пробел оркестратора (пустой Ledger-row в
скелете, поймано lint-docs); ревью — 3 находки, 2 исправлены
(reading-strip, незащищённый Thread.start()), 1 waived (duration-bar,
не покрыт MUST-тестом).

Метрики: исполнитель claude-sonnet-5 (Claude Code), делегирование
фоновым субагентам. Спека ≈123.8 КБ, промпты 127–138. Repair-бюджет:
0 из 4. Токены субагентов: ~1.97M по 11 вызовам; токены оркестратора
харнесс не показывает. Стоимость: $0 — подписка, живого инференса
сверх gate 5 не было.
