tg-agent-bot v1.9.5 — патч: vec_chunks наконец биндится при старте

Условия: баг из issue #3 — на проде с настроенным RAG (EMBEDDING_MODEL/
EMBEDDING_DIM) загрузка любого документа падала с «Storage error. The
document was not saved.», потому что vec_chunks и ключ rag.embedding
никогда не создавались при старте бота.

Результат: все три вызова storage.init_schema в bot.py (main(),
run_selftest(), _live_db()) теперь идут через один общий помощник
_init_startup_schema(conn, cfg), который всегда передаёт настроенную
пару — разъехаться им больше нельзя. main() получил try/except
ConfigError по образцу соседнего _startup_docker_wiring: тем самым
реальный отказ ConfigError (осиротевший vec_chunks, смена пары при
наличии документов) впервые доходит до main() с той же логикой exit 2,
что и любой другой отказ конфигурации. Ревью (0🔴, 2 request-changes +
1 should-fix) закрыто отдельным коммитом: тест на exc_info вместо
структурно нерабочей проверки текста, плюс тест на реальный (не
подменённый) ConfigError через настоящую БД с документом. Версия
1.9.4→1.9.5, счётные строки на реальных цифрах (1638 тестов, 120
мутаций), все 7 гейтов зелёные, тег v1.9.5.

Метрики: исполнитель claude-sonnet-5 (Claude Code), 3 промпта (188–190).
Токены харнесс не отдаёт. Стоимость: ~$0 маржинально — подписка; живой
инференс гейтов 5/7 по референсным ценам, реальных денег не потрачено.
